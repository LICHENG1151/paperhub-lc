## 1. 一句话总结 ★

Kimi K3 是一个 **2.8T 总参 / 104B 激活** 的原生多模态 MoE 大模型，原生支持 **100 万 token 上下文**。核心是用「三条互补维度」重构信息流——**序列（KDA 线性注意力 + Gated MLA 混合）、深度（Attention Residuals 跨层检索）、宽度（Stable LatentMoE，896 选 16 稀疏专家）**，配合训练/数据配方，相较 Kimi K2 取得约 **2.5× 的 scaling 效率提升**。后训练以「通用 / 智能体 / 编码」三域、多档推理力度的 RL 为主。整体性能仅次于 Claude Fable 5 与 GPT-5.6 Sol，**稳定超过其余开源与闭源模型**，且**全量权重开源**。

## 2. 背景与问题

大模型继续 scale 时，三个方向各自撞墙：

| 维度 | 传统做法的瓶颈 |
|------|----------------|
| 序列长度 | 全局 softmax 注意力对长度是 `O(n²)`，百万 token 上下文吃不消 |
| 网络深度 | 标准残差把所有历史压进单一状态 `h_l`，像 RNN 沿时间那样形成深度瓶颈 |
| 模型宽度 | 常规 MoE 中每个被选专家都要收全宽 `d` 维表示，通信/权重流量随激活专家数线性膨胀 |

Kimi K3 的主张：这三条维度要**分别**用「数据依赖的选择性访问」来打通，而不是靠堆算力硬扛。

## 3. 核心思想 ★

架构围绕 **token / channel / layer 三种 mixing** 组织，输入端带原生视觉通路。每个 block = **3 层 KDA + 1 层 Gated MLA**，每个注意力层配一个 Stable LatentMoE 前馈。

**（1）Hybrid Attention（序列维）**
- **KDA（Kimi Delta Attention）**：在 delta-rule 递推上加**逐通道遗忘门** `α_t∈(0,1)^{d_k}`，`β_t` 控制写入强度。分块并行（chunkwise）：块间递归、块内并行，用累积衰减 `Γ` 重标定，兼顾长上下文效率与选择性。
- **Gated MLA**：保留高容量全局注意力；每个 block 末尾及 backbone 末层放 Gated MLA，**保证最后一层永远是全局注意力**。3:1 混合比。

**（2）Attention Residuals / AttnRes（深度维）**
- 把「注意力替代循环」的思路搬到**深度**：每层用可学习 pseudo-query `w_l`，对 embedding + 所有前置层输出做 softmax 加权检索，而非均匀累加。
- **Block AttnRes**：把 L 层切成 N 块，块内求和、块间只对 N 个块级表示做全注意力，把内存/通信开销从 `O(Ld)` 降到 `O(Nd)`。K3 取 **8 块 × 12 层**（含 embedding 记为 9 块）。

**（3）Stable LatentMoE（宽度维）**
- **LatentMoE**：把「全宽」与「路由专家宽度」解耦——共享专家走全宽 `d`，路由专家在紧凑 latent 宽度 `ℓ` 上算，才敢把专家池放到 **896 路由专家、每 token 激活 16 个**（稀疏度 56）。固定 2 个全宽共享专家。
- 极端稀疏放大两个失效模式，用三招稳住：
  1. **Normalized LatentMoE**：聚合后、上投影前插 RMSNorm，抑制路由分支尺度漂移，兼降 val loss。
  2. **SiTU-GLU**：对 SwiGLU 的门/上投影两支都套 `softcap(x,β)=β·tanh(x/β)`（`β1=4`, `β2=25`），保留近原点线性响应又给大值封顶，压低低精度溢出风险。
  3. **Quantile Balancing（QB）**：896 专家的负载均衡超出定步长 bias 更新的稳态区；QB 用「与目标负载匹配的路由分位数」一次前向定出每个专家的 bias，收敛更稳（用 Top-(k+1) 的第 k+1 名当 cutoff，避免额外的 token 侧分位）。

**（4）Native Vision（原生多模态）**：语言与视觉**从训练之初联合优化**，视觉/文本 token 在同一 next-token 目标里交错，无事后对齐阶段。

**（5）Per-Head Muon**：沿用 Muon 优化矩阵参数，对注意力投影按 head 维切分动量矩阵、逐 head 正交化。

## 4. 实现细节

### 4.1 关键规格

| 项 | Kimi K2 → K3 |
|----|--------------|
| 每 token 激活专家 | 8 → **16**（+100%） |
| 训练上下文长度 | 128K → **1M**（8×） |
| ViT 参数 | — → **401M**（MoonViT-V2） |
| 总参 / 激活 | — / — → **2.8T / 104B** |

### 4.2 视觉编码器 MoonViT-V2

- **从零用 next-token 预测训练**（K2.5 及以往用 SigLIP 对比预训练初始化）。动机是**训练稳定性**：SigLIP 初始化的 MoonViT-3D 梯度范数持续偏高且频繁尖峰，从零训的 V2 全程平稳，且视觉评测持平——说明对比预训练不是必需。
- 27 层 ViT（约 0.4B），RMSNorm；图像/视频共享参数，注意力分解为帧内空间 + 帧间时间；投影前 2×2 pixel-shuffle 下采样把视觉 token 减到 1/4，`3584×3584` 输入也能塞进 1M 上下文。

### 4.3 预训练

- **数据**：Web / Code / Math / Knowledge 四大文本域 + 大规模视觉语料（caption、图文交错、OCR、感知、视频、视觉编码）。规则启发式 + 分类器质量打分 + 去重。
- **调度**：scaling law 研究一致偏好 **cosine decay 而非 WSD**（两者最优超参差异大，各自独立搜参后 cosine 终损更低）。Per-Head Muon + K2 的 weight-clipping + QB。
- **渐进扩上下文（四阶段）**：预训练 8K→64K，冷却阶段 256K→1M；把昂贵的长序列计算集中在一小段预算内。合成长上下文数据，强制注意力关注散落在全 1M 上下文中的信息；**无需 RoPE 重缩放/插值**即扩到 1M。

### 4.4 后训练（三阶段）

1. **SFT 冷启动**：扩充复杂智能体任务覆盖；用前代专用模型合成轨迹 + 多阶段校验 + 人在环标注；统一用 **XTML 聊天模板**序列化；**从 SFT 起就 QAT**（MXFP4 权重 + MXFP8 激活）。
2. **RL**：跨 **通用 / 通用智能体 / 编码** 三域，多档推理力度；scaling RL FLOPs 一致提升各能力。
   - **Partial rollout**：缓解长时程任务的长尾延迟，一条长轨迹可跨多次迭代；用**逐 token 正则**容忍极端 off-policy 的数据陈旧。
   - **Reasoning Effort RL**：给每题一个初始 token 预算 `b0(x)`，超过 `τ·b0(x)` 的轨迹奖励置 −1；按 `τ` 分阶段课程（先 max-budget 再退火到小 `τ`），在保正确率的同时压 token。
   - 大量白盒环境/任务：GPU kernel（CUDA/Triton/CuTe/Gluon/ThunderKittens/TileLang，BF16/FP8/FP4，奖励含正确性 + 逼近 roofline 的性能）、投行/数据分析/法律等专业沙箱任务、多模态视觉编码等。
3. **多教师 on-policy 蒸馏** + **MTP/EAGLE-3 草稿模型**做投机解码（目标模型冻结，只训 MTP 层）提升推理效率。

### 4.5 基础设施（§5）

| 组件 | 作用 |
|------|------|
| **FlashKDA** | KDA 的设备内 kernel，显著超过 Triton 参考实现，训练/推理 prefill 共用 |
| **KDA Context Parallelism (KCP)** | 跨设备切分序列维，保住 KDA 状态的串行依赖，使百万 token 训练可行 |
| **MoonEP** | 专家并行方案，**完美负载均衡** + 有界冗余专家，通信 buffer 仅需固定 `S×K`（DeepEP 需 `S×K×R`）；已开源 |
| **AgentENV** | 基于 Firecracker 的 **microVM 沙箱**：增量 checkpoint/恢复、Pause（等推理时可暂停，占沙箱寿命高达 98%）、Fork（无副作用评奖）、Snapshot。训练+评测累计创建 **51,219,741 个沙箱 / 1,505,678 个镜像** |
| **长上下文 RL infra** | co-located 训练把每个 1M 实验压在几百 GPU 内；prefix 写回 CPU DRAM 的外部 KV cache 池，与 KDA 状态一同 offload/预取 |
| **部署** | cache-aware 亲和调度把请求路由到持有其 prefix cache 的集群；一致性哈希把 session 钉到主/备两个集群，界定单集群故障影响 |
| 训练混精 | 多数激活用 block-wise FP8；输出在 FP32 保留以纠正 flash attention 的舍入偏差 |

## 5. 实验与结果

四大能力轴评测（reasoning effort = max, temperature = 1.0）。对手：闭源 Claude Fable 5、GPT-5.6 Sol、Claude Opus 4.8、GPT-5.5；开源 GLM-5.2。

**总基调**：Kimi K3 **紧跟最强闭源双雄（Fable 5 / GPT-5.6 Sol）之后**，但**稳定超过 Opus 4.8、GPT-5.5、GLM-5.2**。

| Benchmark | Kimi K3 | 说明 |
|-----------|---------|------|
| GPQA Diamond | **93.5** | 研究生级推理，与前沿持平 |
| HLE-Full（无/有工具） | 43.5 / 56.0 | 落后 Fable 5、GPT-5.6 Sol，研究级推理是短板 |
| CritPt | 23.4 | 明显落后，研究级推理待提升 |
| DeepSWE | 67.5 | 落后双雄，领先 Opus 4.8 / GPT-5.5 |
| Terminal-Bench 2.1 | 88.3 | 几乎追平 GPT-5.6 Sol（88.8） |
| ProgramBench | **77.8** | 最佳 |
| FrontierSWE（长时程） | 81.2 | 第二，仅次于 Fable 5（86.6），远超其余 |
| SWE-Marathon（GPU kernel） | **42.0** | 领先 Fable 5 约 7 分 |
| BrowseComp | **91.2** | 智能体 SOTA |
| DeepSearchQA | **95.0 (F1)** | SOTA |
| MCPMark-Verified | **94.5** | SOTA |
| Harvey Lab-AA（法律） | **94.6** | 准则通过率 SOTA |

- **编码/智能体**是强项，多个 agentic 套件取 SOTA；主要例外是 Elo 评级的知识型工作套件（GDPval-AA 等），由 Fable 5 领跑，K3 第三。
- **短板**明确写出：research-level reasoning（HLE、CritPt）与顶级闭源仍有差距。

## 6. 结论与局限

- **结论**：三维信息流重构 + 稳定化的极稀疏 MoE + 原生多模态 + 三域多档 RL，能在开源模型里做到前沿级，且 2.8T 规模下靠基础设施协同设计把成本压住。**全量权重开源**。
- **局限（含笔者判断）**：
  - 研究级推理（HLE-Full / CritPt）与 Fable 5 / GPT-5.6 Sol 有实打实差距，作者自己点名为改进方向。
  - 2.5× scaling 效率、QB、SiTU-GLU 等增益多以「val loss / 下游 benchmark 更好」佐证，**缺少对各组件的严格消融拆解**（哪一招贡献几何未逐项量化）。
  - 评测存在配置脚注（H20 校准分支、部分分数引自第三方榜、部分对手跑 fallback/downgraded），跨模型可比性需读脚注，不能只看单数字。

## 7. 个人评述与启发 ★

- **可借鉴 —— 「三维选择性访问」是清晰的组织框架**：序列/深度/宽度各自「数据依赖地选择要读什么」，比单纯堆层堆专家更有工程抓手。我们做长序列调度/状态管理时，KDA 的「块间递归 + 块内并行」和 AttnRes 的「块级表示 + online softmax 合并」都是可直接对照的分块思路。
- **可借鉴 —— 稳定性优先于「预训练先验」**：MoonViT-V2 从零训而非 SigLIP 初始化，纯粹为梯度稳定让路且不掉点。提醒我们别默认「热启动一定更好」，联合优化里稳定性可能是更硬的约束。
- **值得抄的工程点**：MoonEP 的完美均衡 + 有界冗余（buffer 从 `S×K×R` 降到 `S×K`）、AgentENV 的 Pause（等推理时暂停释放 98% 生命周期资源）与 Fork（无副作用评奖）——都是长时程智能体 RL 的省钱关键，且 MoonEP 已开源，可拉来看。
- **要注意 —— QAT 从 SFT 起贯穿后训练**：MXFP4 权重/MXFP8 激活不是最后一步量化，而是全程感知。若我们要部署低精度推理，应把量化提前进训练环，而非事后一刀切。
- **存疑待验**：cosine 一致优于 WSD 的结论依赖「各自独立搜参」，迁到我们规模是否成立需小规模复核；SiTU-GLU 的 `β1=4 / β2=25` 是否要随宽度/精度重调，论文未给缩放规律。
