# 2025 · 高效视觉编码与稀疏语言骨干

**状态**：速览

> 原文：[Seed1.5-VL Technical Report](https://arxiv.org/abs/2505.07062)。本次为速览归档，不代表已复现实验。
> [当月索引](../00-README.md) · [本篇导航](README.md)

## 一句话总结

Seed1.5-VL 用原生动态分辨率 Seed-ViT、2×2 池化与 MLP 接入 20B 激活参数 MoE，控制高分辨率视觉 token 成本。

## 核心思想

- 532M Seed-ViT：27 层、14×14 patch、2D RoPE；原生变分辨率，按图像掩码打包 token。
- 视觉输出经相邻 2×2 平均池化，再经两层 MLP 接入 LLM；同等 patch 数下视觉序列缩短为四分之一。
- 保留视觉编码器以压缩高分辨率输入；编码器与语言骨干不对称还需要视觉 token 重分配来平衡训练负载。

## 验证依据与阅读范围

- PDF §2 / Table 1 给出模型组件与 Seed-ViT 超参；摘要报告 20B 激活语言骨干与 60 项公开基准。
- §5.1 给出大规模预训练并行与负载均衡方案，公开 API 部署属于模型整体证据。

- 本次核对范围：摘要、§2 架构与 Table 1、训练系统概览。
- 证据等级：A；所有性能结论均为作者报告，未在本地独立复现。

## 结论与局限

多模态数据和训练规模会显著影响能力，不可用跨模型成绩替代结构消融。
